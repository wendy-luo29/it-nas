## 1. 项目简介

面向 LSP 物流系统报价、计费、申报链路的自动化测试资产库，覆盖「需求 → 用例 → 脚本 → 执行 → 报告 → 缺陷」全流程。用例与证据按需求批次归档在本库，可执行脚本与 Page Object 在代码仓维护。

技术栈：Python 3.12 + pytest + Playwright + MySQL 只读校验。

## 2. 模块说明

| 模块 | 职责 | 核心接口 | 覆盖状态 |
| --- | --- | --- | --- |
| LspQuote | 手工单报价 / 拦截单 / 出库申请 | UI 页面流转 | 已落地，未接入 CI |
| LspQuote | 燃油附加费 | 报价金额口径 | 用例设计中 |
| LspBackend | 地址校验 | 地址校验接口 | 预留 |
| LspBooking | 申报 / 下单 | — | 预留 |

## 3. 技术栈与依赖

- 语言 / 框架：Python 3.12、pytest、Playwright
- 数据库：MySQL（只读账号，`autocommit=True`）
- 报告：pytest-html / JUnit XML / Excel
- 通知：飞书 Webhook（凭证走环境变量）
- 依赖的外部服务：承运商询价接口、SCP / WMS / ERP 推送

## 6. 约定

1. 目录用 `UR-` 前缀，正文与 `case_id` 保持 `REQ-` 前缀。
2. 每个需求批次目录自包含，交接时无需跨目录查找。
3. `发布文档/` 必须写清分支与 commit，便于 AI 通过 git 日志反查代码。
4. 测试报告不允许只写通过数，必须含覆盖范围、缺陷映射、跳过原因。
