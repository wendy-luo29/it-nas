# 2026-11-15：地址校验 v2.1 规则确认

## 变更概要
业务方一次性确认了地址校验接口的所有规则（R-1 到 R-9），
此前散落在代码注释和临时文档里的隐含约定被正式化。

## 具体变更
- country 字段接受 "AU" 或 "Australia"，默认值 Australia
- not-found 返回 HTTP 200 + `reason="address not found"`（不是 404）
- state 全名自动标准化为缩写存入 stateCode
- address/address2 仅用于 PO Box 检测
- is_return=true 时 adviceAddress 规则 【待确认 v2.2】
- DB 查询 suburb 大小写不敏感（UPPER() 包装）
