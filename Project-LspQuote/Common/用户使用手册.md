# 用户使用手册

面向测试同学与研发同学，说明如何在本项目里准备环境、执行测试、使用技能。

## 1. 环境准备

### 1.1 依赖安装

```powershell
cd ai-test-framework
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install --with-deps chromium
```

### 1.2 配置

| 文件 | 作用 | 是否入库 |
| --- | --- | --- |
| `config/base.yaml` | 通用默认值（env / services / database / report） | 是 |
| `config/env.yaml` | 本机差异（服务地址、账号） | 是，不含口令 |
| `.env` | 敏感凭证（DB 口令、飞书 Webhook） | 否 |

必需环境变量：

| 变量 | 用途 |
| --- | --- |
| `TEST_DB_PASSWORD` | 只读库口令 |
| `FEISHU_WEBHOOK` | 报告推送（可选） |

> 配置采用深度合并：`env.yaml` 同名键覆盖 `base.yaml`，其余保留。缺少被测服务地址或鉴权 Token 时，套件在会话级自检直接失败，不会逐条 skip 造成假通过。

## 2. 执行测试

```powershell
# 全量
python -m pytest -q

# 单条用例
python -m pytest tests/ui/test_example_home.py -q

# 只看某类
python -m pytest -m api -q
python -m pytest -m ui -q

# 输出 HTML 与 JUnit
python -m pytest -q --html=reports/report.html --self-contained-html --junitxml=reports/junit.xml
```

执行前自检：

```powershell
python scripts/knowledge_guard.py --strict
```

## 3. 技能使用

技能按固定顺序执行，前一环节门禁不通过不得进入下一环节：

| 顺序 | 技能 | 输入 → 输出 |
| --- | --- | --- |
| 1 | `requirement-enrichment` | 原始材料 → 纯净接口文档 + 补充清单 |
| 2 | `review-requirements` | 需求文档 → 评审记录（唯一可写 `knowledge/rules` 的环节） |
| 3 | `split-requirements` | 需求 → AC 清单 + impact-index |
| 4 | `design-testcases` | 需求 + 知识库 → YAML/Excel 用例 |
| 5 | `review-testcases` | 用例 → 评审记录 |
| 6 | `test-script` | 用例 → pytest 脚本 |
| 7 | `code-review` | 脚本 → 门禁结论 |
| 8 | `run-tests` | 脚本 → 执行结果 |
| 9 | `test-report` | 结果 → 报告 + Excel |
| 10 | `bug-analysis` | 失败用例 → 缺陷单（MD + XLSX） |

触发方式：在对话中直接描述任务，例如「用 design-testcases 设计 REQ-004 的用例」。

## 4. 产物位置

| 产物 | 位置 |
| --- | --- |
| 用例清单 / Excel | 本库 `UR-xxx-*/测试用例/用例文件/` |
| 测试报告 | 本库 `UR-xxx-*/测试报告.md` |
| 缺陷单 | 本库 `UR-xxx-*/测试用例/用例文件/`（或代码仓 `reports/bugs/`） |
| 脚本与 Page Object | 代码仓 `tests/`、`pages/` |
| HTML 报告 | 代码仓 `reports/report.html` |

## 5. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 用例全部 skip | 配置未加载或服务地址缺失 | 检查 `config/env.yaml` 与 `.env`，运行会话级自检 |
| 数据库连不上 | 口令含中文导致 latin-1 编码错误 | 使用 ASCII 口令或切换 `mysql-connector-python` |
| 新插入任务读不到 | 隔离级别 REPEATABLE READ | 连接已设 `autocommit=True`，勿关闭 |
| 报告推送失败 | 缺 `FEISHU_WEBHOOK` | 本地 `.env` 或 CI Secret 配置 |
| 用例 Excel 内容被裁切 | 固定行高 | 使用 `design-testcases` 的最新导出脚本 |
