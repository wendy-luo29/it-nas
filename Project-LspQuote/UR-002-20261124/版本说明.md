# UR-002-20261124 版本说明

## 1. 需求描述

- 需求标题：新增承运商 AU.TGE.PRIORITY.PRO 接入报价计费（`POST /quote/price_sync`）
- 提出方：业务方（来源 Apifox 导出 OpenAPI 3.0.1，LspQuote / QuoteTaskController）
- 需求类型：变更（承运商接入 `carrier_onboarding`；接口为存量，契约不变）
- 需求版本：v1.0
- 优先级：待确认

## 2. 功能点

| 编号 | 功能点 | 验收标准（AC） | 状态 |
| --- | --- | --- | --- |
| AC-01 | AU.TGE.PRIORITY.PRO 能被策略 / VIR 选中 | 策略与 VIR 两种入口均可选中 PRO | v1.0 |
| AC-02 | 按 PRO 价卡 / 重量段 / fuel / zone 计费 | 每一步四舍五入保留三位小数 | v1.0 |
| AC-03 | 仅支持 `calcMode=1`，箱规校验与过滤 | 超箱规 / 无价卡 / 无收件区域时过滤 PRO | v1.0 |
| AC-04 | 与存量承运商比价择优 | `isBest=1` 全局唯一，恰 1 行 | v1.0 |
| AC-05 | PRO 计费任务正确落库 | `lsp_quote_task.status=200`、`predict_calc_mode=1` | v1.0 |
| AC-06 | 未知仓库 / 不存在的 carrierId → HTTP 500 | 修复前不可发版 | 待验证 |

## 3. 改动点

| 类型 | 内容 | 影响范围 |
| --- | --- | --- |
