## 2. 功能点

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| AC-01 | 正常地址校验通过 | state + postcode + suburb 命中 `lsp_address_suburb_postcode` |
| AC-02 | 收地址错误 | 不命中返回 HTTP 200 + `reason="address not found"`，非 404 |
| AC-03 | 国家编码不支持该国 | country 只接受 `AU` / `Australia`，默认 Australia |

补充规则：state 全名自动标准化为缩写；address/address2 仅用于 PO Box 检测；suburb 查询大小写不敏感。
