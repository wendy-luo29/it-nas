## 五、本次设计的关键假设与待确认

1. 燃油计费公式沿用 REQ-002 口径：`final = ROUND(base_fee × (1 + fuel_rate), 3)`，仅燃油系数变化。
2. 需求未给出**生效时间**与**配置载体**（`lsp_carrier_rate.fuel_rate` 或独立燃油配置表），用例以“查询生效记录”描述并标【待确认】。
3. Allied Express `26.9%+16.6%=43.5%` 未说明是合并单费率还是两段独立费率，金额断言按合计 43.5% 设计，两种实现允许 ≤0.001 差异。
4. Hunter Express `WA=29%+7=36%` 按“WA 区域 +7 个百分点”理解，标【待确认】。
5. DFE `33.1%（接口计费）` 理解为燃油率由承运商接口返回，系统不重复叠加本地燃油，标【待确认】。
6. 需求表格未给 zone 维度；AUPOST 的 N/Y 与 E/Express-Post 按同 code 同费率处理。
